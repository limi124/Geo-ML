# 数据准备

## 案例区域与数据说明

教程示例以**黑龙江省齐齐哈尔市甘南县**为案例背景，演示多源栅格对齐、空间验证与地表温度（LST）建模工作流，定位为教学与方法演示，不作为业务级遥感产品。

为保持 GitHub 仓库轻量，原始栅格与边界矢量不直接托管在 Git 仓库内。你可以通过以下三种方式之一准备 `data/raw/` 并运行全部 8 章教程：

## 方式 A：下载完整案例数据（百度网盘，推荐）

直接下载教程配套的多源栅格与行政区边界数据：

- **百度网盘链接**：https://pan.baidu.com/s/14DApydGCLS6j1u2LkQDnaw?pwd=npxd
- **提取码**：`npxd`

下载并解压后，确保以下文件位于 `data/raw/` 目录中：

```text
data/raw/
├── GNLST.tif               # 目标变量：地表温度（决定参考网格）
├── GNDEM.tif               # 预测变量：数字高程
├── GNNDVI.tif              # 预测变量：植被指数
├── GNTEM.tif               # 预测变量：气温
├── precip_sum_2020.tif     # 预测变量：降水
├── soil_moist_mean_2020.tif# 预测变量：土壤水分
└── GanNan.shp / .shx / .dbf / .prj / .cpg
```

## 方式 B：免下载，一键生成合成示例数据

如果你不想下载网盘文件，可运行仓库自带的合成数据生成脚本：

```bash
conda run -n geoml python tools/make_demo_data.py
```

该脚本会在 `data/raw/` 中生成一套**纯数学合成的示例栅格与边界**，完整复现多分辨率（约 250 m–10 km）、不同坐标系（UTM 52N + EPSG:4326）和不同 NoData 约定（未声明零值填充、NaN、`-9999`）的真实教学场景。生成的文件仅用于本地学习与测试，已被 `.gitignore` 忽略。

> **注意**：合成数据用于跑通流程与理解方法，其数值与 Notebook 正文里基于原始案例的文字描述（如具体像元数、RMSE 数值）会有差异，属于正常现象。

## 方式 C：使用自己的同结构数据

如果你拥有其他研究区的同类多源栅格，可按方式 A 的文件名与波段约定放入 `data/raw/`。开始分析前，请先核实数据来源、时间粒度、物理单位、坐标系、NoData 约定及使用许可。
