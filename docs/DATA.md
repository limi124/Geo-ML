# 数据准备

## 案例区域

教程示例使用黑龙江省齐齐哈尔市甘南县的多源栅格。它用于演示栅格预处理、空间验证和机器学习工作流，不作为业务级地表温度产品。

## 本地数据目录

公开仓库不包含源栅格或行政区边界。准备好有权使用的数据后，将以下文件放入 `data/raw/`：

```text
GNLST.tif
GNDEM.tif
GNNDVI.tif
GNTEM.tif
precip_sum_2020.tif
soil_moist_mean_2020.tif
GanNan.shp
GanNan.shx
GanNan.dbf
GanNan.prj
GanNan.cpg
```

文件名、波段含义和栅格布局需符合 Notebook 中的数据读取代码。原始数据可能来自不同年份和不同分辨率，开始分析前请核实来源、时间、单位、坐标系、NoData 约定及使用许可。

## 使用与许可

源数据和由其生成的样本、栅格、图件及模型结果不由本仓库的 MIT 许可覆盖。使用者需自行确认来源方的使用、再分发和署名要求。本仓库不提供下载链接，因为当前无法确认数据发布方允许公开分发。

源数据的具体时间和单位如果无法从可信元数据确认，应在分析中明确标注未知，不要只根据数值范围推断。
